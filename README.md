# calculadora de media de nota 
##### Programa simples que recebe duas notas de um aluno e calcula sua média.

# tecnologia usada
#### python

# como usar a calculadora 
- requisitos: python 3 instalado
- baixe o projeto: calculadora de média
- execute no VSCODE
- uso: digite as duas notas quando solicitado

# exemplo de uso
##### a média e calculada usando: media = (nota1 + nota2) / 2
